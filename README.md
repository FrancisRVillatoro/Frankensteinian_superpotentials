# Frankensteinian_superpotentials

Reproducibility code for the manuscript

> F. R. Villatoro, *Frankensteinian superpotentials: canonical decomposition, sewing regularity and singular limits*, manuscript submitted to **Physical Review D** (2026).

The repository contains the Python code used to generate the two figures in the manuscript. The calculations are direct evaluations of the closed-form expressions discussed in the paper.

## Contents

| File | Description |
| --- | --- |
| `make_figures.py` | Generates all manuscript figures in PDF and PNG formats. |
| `figures/` | Figure files generated by the script. |
| `requirements.txt` | Minimal Python dependencies. |
| `CITATION.cff` | Citation metadata for GitHub and Zenodo. |
| `LICENSE` | MIT License. |

## Reproducing the figures

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python make_figures.py
```

The script writes only inside `figures/`.

It has been tested with Python 3.13.5, NumPy 2.3.5, and Matplotlib 3.10.8.

## Map to the manuscript

| Output | Manuscript item |
| --- | --- |
| `figures/fig_structural_decomposition_prd_v5.pdf` | Structural comparison between smooth inflection locations and exact Frankensteinian sewing levels. |
| `figures/fig_bps_regularization_v5.pdf` | Loss of regularity of the canonical flow derivative along the singular family approaching the tail-tail limit. |

PNG versions are also generated for convenient inspection.
